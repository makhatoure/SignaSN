# 🇸🇳 SignaSN — Plateforme Citoyenne de Signalement

**SignaSN** est une application mobile citoyenne conçue pour le Sénégal permettant à chaque habitant de documenter et géolocaliser les anomalies du quotidien (infrastructures dégradées, insalubrité, loyers abusifs, pannes d'eau/électricité, etc.).

---

## 🌟 Philosophie : "La Preuve avant Tout"
Plutôt que d'alimenter les plaintes informelles sur les réseaux sociaux, **SignaSN** transforme une difficulté individuelle en un **fait documenté, géolocalisé et validé par la communauté**, directement exploitable par les journalistes d'investigation et les décideurs.

---

## 🚀 Fonctionnalités Clés (MVP)
- 📸 **Prise de photo & Preuve factuelle** : Enregistrement de l'anomalie sur le terrain.
- 📍 **Géolocalisation automatique** : Marqueurs précis sur carte interactive (Dakar & Régions).
- 🔊 **Notes Vocales** : Accessibilité maximale pour tous les citoyens.
- 👥 **Bouton "Moi aussi"** : Confirmation communautaire montrant l'urgence de la situation.
- 🔴 🟠 🟢 **Suivi des statuts** : *Signalé ➔ En cours ➔ Résolu*.
- 📰 **Module Média & Journalistes** : Exportation de visuels synthétiques pour relayer l'information dans les JT et presse locale.

---

## 🛠️ Stack Technique (Budget 0 €)
- **Frontend Mobile** : [Flutter](https://flutter.dev) (Android & iOS).
- **Backend & Database** : [Supabase](https://supabase.com) (PostgreSQL, Auth & Storage).
- **Cartographie** : OpenStreetMap / Leaflet (100% gratuit).
